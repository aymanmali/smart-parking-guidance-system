# Security Policy

## Reporting a Vulnerability

If you find a security issue in the FastAPI server, WebSocket stream, MQTT/RS-485 bridge, or ESP32 firmware, please **do not** open a public GitHub issue.

Instead, report it privately via **ayman.m.ali148@gmail.com** or [GitHub Security Advisories](https://github.com/aymanmali/smart-parking-guidance-system/security/advisories/new) with reproduction steps and impact details.
